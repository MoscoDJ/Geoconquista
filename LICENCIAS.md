# Licencias de Geoconquista

Geoconquista usa licencias distintas según el tipo de material. La decisión y sus motivos están en [ADR-003](docs/decisions/ADR-003-licencias.md).

| Material | Dónde | Licencia |
|---|---|---|
| Código | `apps/`, `packages/`, `tools/` y scripts | [GNU AGPL-3.0-or-later](LICENSE) |
| Documentación, reglas, cartas, textos y datos del mapa | `docs/`, datos de contenido | [CC BY-SA 4.0](LICENSES/CC-BY-SA-4.0.txt) |
| Ilustraciones, iconos y composiciones | `assets/` (la licencia de cada archivo está en `assets/manifest.json`) | [CC BY-SA 4.0](LICENSES/CC-BY-SA-4.0.txt) |
| Voces, efectos y música generados con ElevenLabs | `assets/` | [Licencia de audio de Geoconquista](LICENSES/LicenseRef-Geoconquista-Audio.md): solo se redistribuyen como parte del juego |
| Fuentes tipográficas | Junto a cada fuente | SIL Open Font License 1.1 |
| Geometría de países | Datos del mapa | Natural Earth, dominio público |

El nombre «Geoconquista» y su logotipo no están incluidos en estas licencias: ver [MARCA.md](MARCA.md).

Para aportar, lee [CONTRIBUTING.md](CONTRIBUTING.md).
