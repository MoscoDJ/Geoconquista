# Geoconquista licenses

> This is the English translation of [LICENCIAS.md](LICENCIAS.md). The Spanish version is canonical: if they differ, the Spanish version prevails (D-29).

Geoconquista uses different licenses depending on the type of material. The decision and its reasons are in [ADR-003](docs/decisions/ADR-003-licencias.en.md).

| Material | Where | License |
|---|---|---|
| Code | `apps/`, `packages/`, `tools/` and scripts | [GNU AGPL-3.0-or-later](LICENSE) |
| Documentation, rules, cards, texts and map data | `docs/`, content data | [CC BY-SA 4.0](LICENSES/CC-BY-SA-4.0.txt) |
| Illustrations, icons and compositions | `assets/` (each file's license is in `assets/manifest.json`) | [CC BY-SA 4.0](LICENSES/CC-BY-SA-4.0.txt) |
| Voices, sound effects and music generated with ElevenLabs | `assets/` | [Geoconquista Audio License](LICENSES/LicenseRef-Geoconquista-Audio.en.md): redistributed only as part of the game |
| Fonts | Alongside each font | SIL Open Font License 1.1 |
| Country geometry | Map data | Natural Earth, public domain |

The name “Geoconquista” and its logo are not included in these licenses: see [MARCA.md](MARCA.en.md).
