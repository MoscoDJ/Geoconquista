# Geoconquista

> This is the English translation of [README.md](README.md). The Spanish version is canonical: if they differ, the Spanish version prevails (D-29).

A social geopolitical strategy game, a hybrid of tabletop and digital, in Spanish and English. It is played in person, with face-to-face negotiation: each player rolls the dice by swiping on their phone and they land on the tablet, in full view of everyone. A large screen shows the board, a tablet acts as the table console and each player checks their secret armies on their phone. It runs on a local network, without Internet.

**Status:** v0 rules approved (G1). There is no product code yet: the project follows *Documentation First* and the code starts when gate G3 is approved.
