# Name and logo

> This is the English translation of [MARCA.md](MARCA.md). The Spanish version is canonical: if they differ, the Spanish version prevails (D-29).

“Geoconquista” and its logo identify the official project. They are not included in the code or content licenses ([LICENCIAS.md](LICENCIAS.en.md)).

**You may, without asking for permission:**
- talk about Geoconquista, write about it and link to it;
- say that your project is “based on Geoconquista” or “compatible with Geoconquista”;
- use the name in games, tournaments or reviews.

**You need a different name** if you distribute a modified version of the game. That way no one confuses your version with the official one. Your version can still use all the code and content under their licenses.

If you have any questions, open an *issue* in the repository.
